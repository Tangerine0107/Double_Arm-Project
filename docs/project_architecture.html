工程化风险 (Risks)
  • 模型不一致：arm.urdf 与 double_arm_with_hands.urdf 并存，可能不同步。
  • 安全配置失败仍用默认值：应改为「拒绝启动」而非降级默认。
  • 感知外参缺失：不应继续进入抓取规划，需前置校验。
  • OpenPI Bridge 监听 0.0.0.0：需加认证、watchdog 与动作边界。
  • 文档不足：根目录 README 与统一构建/部署文档缺失。
  • 仓库边界混乱：多个嵌套 Git 目录需统一。
  • 测试薄弱：硬件、动力学补偿、任务状态机仍需更多单元测试。
